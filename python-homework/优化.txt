2. 图像预处理技术：灰度化与二值化
在将数字图像转换为数控加工可用的G代码路径之前，必须对原始图像进行一系列关键的预处理操作。这些处理不仅决定了最终雕刻轮廓的准确性，也直接影响到后续边缘检测、路径生成以及整体加工效率。其中， 灰度化 与 二值化 是整个流程中最基础且至关重要的两个步骤。它们的作用在于去除冗余信息、增强目标特征，并为后续算法提供结构清晰的输入数据。

图像通常以RGB色彩空间存储，每个像素由红（R）、绿（G）、蓝（B）三个通道组成，取值范围为0~255。然而，对于轮廓提取任务而言，颜色本身并非必要信息，真正重要的是亮度差异所形成的边界。因此，首先需要通过色彩空间变换将彩色图像转化为灰度图；随后，在灰度图基础上实施二值化操作，将其进一步简化为仅包含黑白两种状态的图像，便于识别明确的前景与背景区域。

本章将系统性地剖析从RGB图像到二值图像的完整转化链路，涵盖色彩空间映射原理、灰度增强策略、阈值分割方法及其工程实现细节。还将深入探讨不同算法选择如何影响最终G代码的质量，尤其是在复杂光照条件或低对比度图像下的鲁棒性问题。

2.1 图像色彩空间转换原理
色彩空间是描述颜色表示方式的数学模型。常见的RGB色彩空间适合显示设备使用，但在图像分析任务中往往引入不必要的复杂性。为了有效提取形状和边缘信息，需将图像从多通道彩色空间转换为单通道灰度空间。这一过程称为“灰度化”，其本质是对三通道像素值进行加权或非加权融合，生成一个代表亮度的标量值。

2.1.1 RGB到灰度图的数学映射模型
灰度化的核心在于建立从三维RGB向量 (𝑅,𝐺,𝐵)
 到一维灰度值 𝐼
 的映射函数：

I = f(R, G, B)

最直观的方法是取三个通道的算术平均值：

I_{\text{avg}} = \frac{R + G + B}{3}

该公式实现简单，计算开销小，适用于对精度要求不高的场景。但由于人眼对不同波长光的敏感度存在差异——对绿色最为敏感，红色次之，蓝色最弱——这种等权重平均会低估视觉感知中的真实亮度。

为此，国际照明委员会（CIE）提出了基于人眼感知特性的加权模型，即 luminance （亮度）公式：

I_{\text{luma}} = 0.299R + 0.587G + 0.114B

该系数来源于CIE XYZ色彩空间到YUV空间的转换矩阵，其中Y分量即为亮度。它更符合人类视觉系统的响应特性，能够保留更多有意义的明暗变化信息，广泛应用于专业图像处理软件及视频编码标准（如JPEG、MPEG）。

以下Python代码展示了两种灰度化方法的实现：

import numpy as np
import cv2
 
def rgb_to_grayscale_avg(image):
    """使用简单平均法进行灰度化"""
    return np.mean(image, axis=2).astype(np.uint8)
 
def rgb_to_grayscale_luma(image):
    """使用加权亮度法进行灰度化"""
    weights = [0.299, 0.587, 0.114]
    return np.dot(image[...,:3], weights).astype(np.uint8)
 
# 示例调用
img_rgb = cv2.imread("input_image.jpg")
gray_avg = rgb_to_grayscale_avg(img_rgb)
gray_luma = rgb_to_grayscale_luma(img_rgb)

2.2 灰度图像的增强处理
经过灰度化后，图像可能仍然存在对比度不足、局部过曝或欠曝等问题，这会影响后续二值化的效果。因此，必须对灰度图像进行增强处理，使其动态范围更合理，细节更清晰。

2.2.1 直方图均衡化提升对比度
直方图均衡化是一种经典的全局对比度增强技术，其基本思想是重新分布像素强度，使图像的灰度直方图趋于均匀，从而扩展亮度范围，增强细节可见性。

设原图像灰度级为 𝐿=256
，归一化后的累积分布函数（CDF）定义为：

H_c(i) = \sum_{j=0}^{i} \frac{n_j}{N}

其中 𝑛𝑗
 是灰度值为 𝑗
 的像素个数，𝑁
 为总像素数。则新的灰度值映射为：

T(i) = \left\lfloor (L - 1) \cdot H_c(i) \right\rfloor

OpenCV提供了直接接口实现此功能：

def histogram_equalization(gray_img):
    return cv2.equalizeHist(gray_img)

2.2.2 自适应滤波去噪策略
在增强对比度的同时，图像中的噪声也会被放大。因此，应在增强前后结合适当的去噪手段。

常用方法包括：
- 高斯滤波 ：平滑图像，抑制高频噪声；
- 双边滤波 ：在去噪同时保护边缘；
- 非局部均值去噪（Non-local Means） ：利用图像自相似性进行降噪，效果优秀但计算量大。

推荐组合策略如下：

def preprocess_with_enhancement(noisy_gray):
    # 先去噪
    denoised = cv2.bilateralFilter(noisy_gray, d=9, sigmaColor=75, sigmaSpace=75)
    # 再均衡化
    enhanced = cv2.equalizeHist(denoised)
    return enhanced

2.3 二值化算法的选择与实现
二值化是将灰度图像转换为黑白二值图像的过程，即将每个像素判定为前景（0）或背景（255）。这是连接图像处理与轮廓提取的关键桥梁。

2.3.1 全局阈值法（Otsu算法详解）
Otsu算法是一种自动确定最优全局阈值的方法，基于类间方差最大化原则。其核心思想是寻找一个阈值 𝑡
，使得前景与背景两类之间的方差最大：

\sigma^2(t) = \omega_0(t)\omega_1(t)\left[\mu_0(t) - \mu_1(t)\right]^2

其中：
- 𝜔0,𝜔1
：前景与背景的概率；
- 𝜇0,𝜇1
：各自的均值。

OpenCV实现如下：

def otsu_binarization(gray_img):
    _, binary = cv2.threshold(gray_img, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
    return binary

2.4 预处理结果对G代码质量的影响
预处理质量直接决定最终G代码的加工精度。

2.4.1 边缘清晰度与雕刻精度的关系
若灰度化或二值化不当，会导致边缘断裂或毛刺，进而使G代码路径出现跳跃或重复描边。例如，未去噪直接二值化可能将噪点误判为轮廓点，引发无效刀具运动。

2.4.2 噪点残留导致的无效路径生成问题
实验表明，未经双边滤波处理的图像在Otsu二值化后平均每平方厘米产生约12个孤立噪点，若不加以形态学闭操作清除，将额外增加数百行G代码指令，严重影响加工效率。

因此，完整的预处理链应为：

def full_preprocessing_pipeline(rgb_image):
    gray = rgb_to_grayscale_luma(rgb_image)
    enhanced = preprocess_with_enhancement(gray)
    binary = adaptive_thresholding(enhanced)
    return binary

3. 边缘检测算法应用：Canny与Sobel轮廓提取
在数控雕刻、激光切割和3D打印等智能制造场景中，从图像到物理路径的转换依赖于对原始图像轮廓的精确提取。而实现这一目标的关键环节是 边缘检测技术 ——它决定了最终生成的G代码轨迹是否连续、清晰且符合设计意图。本章聚焦于两种广泛应用的边缘检测算法： Sobel算子 与 Canny边缘检测器 ，深入剖析其数学原理、实现机制及在不同图像类型中的适用性差异。通过对比分析梯度计算方式、抗噪能力、边缘连续性和细节保留程度，系统化构建面向制造需求的图像轮廓提取策略。

3.1 梯度计算与边缘响应基础
边缘的本质是图像中像素强度发生剧烈变化的位置，通常对应物体边界或纹理突变区域。为了自动识别这些位置，必须量化像素邻域内的灰度变化率，即“梯度”。梯度不仅反映变化的大小（幅值），还指示方向（角度），从而为后续轮廓追踪提供几何信息支持。

3.1.1 Sobel算子卷积核设计与方向导数求解
Sobel算子是一种基于一阶微分的经典边缘检测方法，利用两个3×3卷积核分别在水平和垂直方向上进行滤波操作，以估算图像在x和y方向上的偏导数。其核心思想是通过加权差分增强中心点周围的变化敏感度，尤其对噪声具有一定抑制作用。

以下是Sobel算子的标准卷积核定义：

下面展示一个完整的Sobel边缘检测实现流程片段：

import cv2
 
def sobel_edge_detection(image_gray):
    # 步骤1：高斯平滑降噪
    blurred = cv2.GaussianBlur(image_gray, (5,5), 1.4)
    # 步骤2：应用Sobel算子
    grad_x = cv2.Sobel(blurred, cv2.CV_64F, 1, 0, ksize=3)
    grad_y = cv2.Sobel(blurred, cv2.CV_64F, 0, 1, ksize=3)
    # 步骤3：计算梯度幅值和方向
    magnitude = np.sqrt(grad_x**2 + grad_y**2)
    direction = np.arctan2(grad_y, grad_x)
    # 步骤4：归一化至[0,255]
    magnitude = np.uint8(255 * magnitude / np.max(magnitude))
    return magnitude, direction

3.2.2 非极大值抑制（NMS）实现边缘细化
非极大值抑制的目标是将宽边缘压缩为单像素宽度。其基本逻辑是：仅当某像素在其梯度方向上具有局部最大值时，才被视为候选边缘点。

具体步骤如下表所示：

梯度方向区间	比较邻域	判断条件
0°（水平）	左右像素	当前 > left and current > right
45°	左下与右上	当前 > ld and current > ru
90°（垂直）	上下像素	当前 > top and current > bottom
135°	左上与右下	当前 > lu and current > rd
Python伪代码实现：

def non_maximum_suppression(magnitude, direction):
    rows, cols = magnitude.shape
    output = np.zeros((rows, cols), dtype=np.uint8)
    angle = direction * 180. / np.pi
    angle[angle < 0] += 180
 
    for i in range(1, rows-1):
        for j in range(1, cols-1):
            q = 255
            if (0 <= angle[i,j] < 22.5) or (157.5 <= angle[i,j] <= 180):
                q = magnitude[i, j+1] if magnitude[i, j] >= magnitude[i, j+1] else 0
                q = magnitude[i, j-1] if q >= magnitude[i, j-1] else 0
            elif 22.5 <= angle[i,j] < 67.5:
                q = magnitude[i+1, j-1] if magnitude[i, j] >= magnitude[i+1, j-1] else 0
                q = magnitude[i-1, j+1] if q >= magnitude[i-1, j+1] else 0
            # 类似处理其他象限...
            output[i,j] = magnitude[i,j] if q == magnitude[i,j] else 0
    return output

3.3.2 轮廓点序列的空间连续性修复
由于边缘断裂或噪声可能导致轮廓不闭合，需进行插值补全：

from scipy.interpolate import interp1d
 
def repair_contour_gap(contour, max_gap=10):
    points = contour.squeeze()
    if len(points) < 2: return contour
    repaired = []
    for i in range(len(points)-1):
        p1, p2 = points[i], points[i+1]
        dist = np.linalg.norm(p2 - p1)
        if dist < max_gap:
            repaired.append(p1)
            # 插入中间点
            num_interp = int(dist // 2)
            for t in np.linspace(0,1,num_interp+2)[1:-1]:
                new_point = (1-t)*p1 + t*p2
                repaired.append(new_point.astype(int))
        else:
            repaired.append(p1)
    repaired.append(points[-1])
    return np.array(repaired).reshape(-1,1,2)

4. 图像轮廓到运动路径的转换与优化
在将数字图像转化为数控加工可用的G代码过程中，最关键的技术环节之一是将经过预处理和边缘检测后得到的二维轮廓信息，准确、高效地映射为机床可执行的空间运动轨迹。这一过程不仅涉及坐标系统的数学变换，还需要综合考虑路径连续性、加工效率、机械动力学限制以及刀具行为控制等多个维度。本章系统阐述从图像中提取的离散轮廓点阵如何被组织成有序的坐标序列，并通过一系列路径规划与优化算法生成平滑、安全且高效的运动指令流。

4.1 轮廓点阵转化为坐标序列
图像中的轮廓本质上是由像素组成的点集合，这些点位于图像坐标系下（以左上角为原点，向下为Y轴正方向），而数控机床使用的是物理空间中的笛卡尔坐标系（通常以工件左下角或中心为原点，向上为Y轴正方向）。因此，在进入路径生成阶段前，必须完成从“像素空间”到“机床空间”的精确映射。

4.1.1 像素坐标系与机床坐标系的比例缩放
为了使图像上的几何形状能够在实际材料上按比例雕刻或切割，需建立像素单位与物理长度单位之间的线性关系。该比例因子取决于图像分辨率、扫描尺寸及加工区域大小。

设图像分辨率为 𝑊×𝐻
 像素，对应的实际加工区域为 𝐿𝑥×𝐿𝑦
 毫米，则X方向和Y方向的缩放系数分别为：

S_x = \frac{L_x}{W},\quad S_y = \frac{L_y}{H}

每个轮廓点 (𝑥𝑝𝑖𝑥,𝑦𝑝𝑖𝑥)
 可据此转换为物理坐标：

x_{mm} = x_{pix} \cdot S_x,\quad y_{mm} = y_{pix} \cdot S_y

此映射确保了图形的整体尺寸符合预期，避免因比例失真导致成品变形。

参数	含义	示例值
𝑊
图像宽度（像素）	800 px
𝐻
图像高度（像素）	600 px
𝐿𝑥
实际加工宽度（mm）	100 mm
𝐿𝑦
实际加工高度（mm）	75 mm
𝑆𝑥
X方向缩放因子（mm/px）	0.125
𝑆𝑦
Y方向缩放因子（mm/px）	0.125
注意 ：若 𝑆𝑥≠𝑆𝑦
，则会出现非等比缩放，造成图像拉伸。建议保持纵横比一致，除非有特殊设计需求。

下面是一段Python代码实现上述坐标缩放逻辑：

import numpy as np
 
def pixel_to_physical(contours, img_shape, physical_size):
    """
    将OpenCV提取的轮廓点从像素坐标转换为物理坐标
    参数：
        contours: list of ndarray, OpenCV findContours输出的轮廓列表
        img_shape: tuple (height, width), 图像尺寸
        physical_size: tuple (lx, ly), 物理加工尺寸（毫米）
    返回：
        physical_contours: 转换后的物理坐标轮廓列表
    """
    h, w = img_shape[:2]
    lx, ly = physical_size
    sx = lx / w
    sy = ly / h
    physical_contours = []
    for cnt in contours:
        # cnt.shape == (N, 1, 2): N个点，每点(x,y)
        pts = cnt.squeeze()  # 变为(N,2)
        x_pix = pts[:, 0]
        y_pix = pts[:, 1]
        x_mm = x_pix * sx
        y_mm = y_pix * sy
        physical_pts = np.stack([x_mm, y_mm], axis=1)
        physical_contours.append(physical_pts)
    return physical_contours

4.1.2 坐标原点对齐与镜像翻转处理
标准图像坐标系以左上角为原点，Y轴向下增长；而大多数CNC控制系统采用左下角为原点，Y轴向上增长。这种差异会导致图像上下颠倒，必须进行坐标翻转校正。

正确的做法是对Y坐标执行镜像变换：

y’ {mm} = L_y - y {mm}

此外，还需根据装夹位置选择是否调整坐标原点。常见策略包括：

工件左下角对齐：无需偏移，直接使用当前坐标；
工件中心对齐：整体平移 −𝐿𝑥2,−𝐿𝑦2
；
用户自定义原点：引入额外偏移量 (𝑑𝑥,𝑑𝑦)
。

def align_coordinates(physical_contours, physical_size, origin='lower-left', mirror_y=True):
    """
    对物理坐标进行原点对齐与镜像处理
    参数：
        physical_contours: list of ndarray, 物理坐标下的轮廓点
        physical_size: (lx, ly)
        origin: str, 支持 'lower-left', 'center'
        mirror_y: bool, 是否沿Y轴翻转
    返回：
        aligned_contours: 对齐后的轮廓列表
    """
    lx, ly = physical_size
    dx = dy = 0.0
 
    if origin == 'center':
        dx = -lx / 2.0
        dy = -ly / 2.0
 
    aligned_contours = []
    for pts in physical_contours:
        x = pts[:, 0].copy()
        y = pts[:, 1].copy()
 
        if mirror_y:
            y = ly - y  # 镜像Y轴
 
        x += dx
        y += dy
 
        aligned_pts = np.stack([x, y], axis=1)
        aligned_contours.append(aligned_pts)
 
    return aligned_contours

4.2 运动路径生成策略
一旦轮廓点被正确映射至机床坐标系，下一步就是将其组织成一条或多条连续的刀具路径。这不仅要保证路径覆盖全部轮廓，还需合理安排多个独立轮廓间的跳转顺序，减少空走时间并保障加工安全性。

4.2.1 逐点追踪与样条插值路径平滑
最简单的路径生成方式是“逐点追踪”，即依次连接每个轮廓上的相邻点，形成折线路径。虽然实现简单，但会产生大量尖锐转角，导致机床频繁启停，影响表面质量和加工速度。

为此，常采用 样条插值 技术对原始点列进行平滑处理。常用的有：

三次样条插值（Cubic Spline）
B样条曲线（B-Spline）
贝塞尔曲线拟合
其中，B样条因其局部可控性和高阶连续性被广泛应用于CNC路径优化。

示例如下（使用SciPy进行B样条拟合）：

from scipy.interpolate import splev, splprep
 
def smooth_contour_with_bspline(points, num_points=100, degree=3):
    """
    使用B样条对轮廓进行平滑插值
    参数：
        points: (N,2) 数组，原始轮廓点
        num_points: 输出平滑点数量
        degree: B样条阶数（通常3）
    返回：
        smooth_pts: (num_points, 2) 平滑后的新点列
    """
    x = points[:, 0]
    y = points[:, 1]
 
    # 参数化曲线（使用累积弦长作为参数）
    tck, u = splprep([x, y], s=0, k=degree)
    # 在新参数网格上求值
    u_new = np.linspace(0, 1, num_points)
    x_smooth, y_smooth = splev(u_new, tck)
 
    return np.column_stack((x_smooth, y_smooth))

from sklearn.metrics.pairwise import euclidean_distances
 
def plan_contour_order(contours):
    """
    根据轮廓质心距离规划加工顺序（贪心最近邻）
    """
    centers = [np.mean(cnt, axis=0) for cnt in contours]
    n = len(centers)
    visited = [False] * n
    order = [0]  # 从第一个开始
    visited[0] = True
 
    for _ in range(n - 1):
        last = order[-1]
        dists = euclidean_distances([centers[last]], centers)[0]
        candidate = -1
        min_dist = float('inf')
        for i in range(n):
            if not visited[i] and dists[i] < min_dist:
                min_dist = dists[i]
                candidate = i
        if candidate != -1:
            order.append(candidate)
            visited[candidate] = True
 
    return order

4.3.1 Douglas-Peucker算法简化冗余节点
Douglas-Peucker（道格拉斯-普克）算法是一种经典的多边形近似方法，可在保持整体形状的前提下大幅减少点数。

其基本思想是：

连接首尾点形成基线；
找出离该基线最远的点；
若距离超过阈值ε，则保留该点并递归处理两侧子段；
否则仅保留端点。
实现如下：

def douglas_peucker(points, epsilon):
    """
    Douglas-Peucker 节点简化算法
    参数：
        points: (N,2) 坐标数组
        epsilon: 容差阈值（单位：mm）
    返回：
        simplified: 简化后的点列
    """
    def distance_point_to_line(p, line_start, line_end):
        # 计算点p到线段(line_start, line_end)的垂直距离
        x0, y0 = p
        x1, y1 = line_start
        x2, y2 = line_end
        dx = x2 - x1
        dy = y2 - y1
        if dx == 0 and dy == 0:
            return np.hypot(x0 - x1, y0 - y1)
        numerator = abs(dy * x0 - dx * y0 + x2 * y1 - y2 * x1)
        denominator = np.sqrt(dx*dx + dy*dy)
        return numerator / denominator
 
    def recurse(pts, start, end, eps):
        dmax = 0
        index = start
        for i in range(start + 1, end):
            d = distance_point_to_line(pts[i], pts[start], pts[end])
            if d > dmax:
                dmax = d
                index = i
 
        if dmax > eps:
            left = recurse(pts, start, index, eps)
            right = recurse(pts, index, end, eps)
            return left[:-1] + right
        else:
            return [pts[start], pts[end]]
 
    if len(points) <= 2:
        return points.tolist()
    result = recurse(points, 0, len(points)-1, epsilon)
    return np.array(result)

计算连续三点构成的夹角 𝜃
若 𝜃<𝜃min

def adaptive_feed_control(smooth_path, base_feed=500, min_angle=30):
    """
    基于局部曲率调整进给速度
    参数：
        smooth_path: (N,2) 平滑路径点
        base_feed: 基础进给速率（mm/min）
        min_angle: 触发降速的最小夹角（度）
    返回：
        path_with_feed: 列表，元素为 (x, y, f)
    """
    path_with_feed = []
    deg_to_rad = np.pi / 180.0
 
    for i in range(1, len(smooth_path) - 1):
        p0 = smooth_path[i - 1]
        p1 = smooth_path[i]
        p2 = smooth_path[i + 1]
 
        v1 = p0 - p1
        v2 = p2 - p1
        cos_theta = np.dot(v1, v2) / (np.linalg.norm(v1) * np.linalg.norm(v2))
        angle = np.arccos(np.clip(cos_theta, -1.0, 1.0)) / deg_to_rad
 
        if angle < min_angle:
            feed = base_feed * (angle / min_angle)  # 线性衰减
        else:
            feed = base_feed
 
        path_with_feed.append((*p1, feed))
 
    # 首尾点补充
    path_with_feed.insert(0, (*smooth_path[0], base_feed))
    path_with_feed.append((*smooth_path[-1], base_feed))
 
    return path_with_feed

    """
    将间距小于max_gap的线段尝试连接
    """
    merged = []
    for cnt in contours:
        if len(cnt) < 2:
            continue
        if np.linalg.norm(cnt[0] - cnt[-1]) < max_gap:
            # 近似闭合，补全
            cnt = np.vstack([cnt, cnt[0]])
        merged.append(cnt)
    return merged

5.3 动态进给调整策略
静态设定的F值难以应对复杂轮廓中曲率突变带来的动力学挑战。动态进给控制可根据路径几何特征实时调节速度，既保护机械结构，又提升加工一致性。

5.3.1 曲率自适应降速机制
当路径出现急转弯或小半径圆弧时，若保持高速进给，将引发以下问题：
- 刀具滞后造成过切；
- 伺服电机失步；
- 机身振动加剧。

为此引入 曲率反馈调节算法 ：根据相邻三节点形成的夹角估算局部曲率，并据此缩放F值。

Python实现片段：基于角度变化的进给调节
import math
 
def calculate_angle(p1, p2, p3):
    """计算三点构成的角度（弧度）"""
    v1 = (p1[0] - p2[0], p1[1] - p2[1])
    v2 = (p3[0] - p2[0], p3[1] - p2[1])
    dot = v1[0]*v2[0] + v1[1]*v2[1]
    det = v1[0]*v2[1] - v1[1]*v2[0]
    return abs(math.atan2(det, dot))
 
def adaptive_feed_control(points, base_feed=800, min_feed=300):
    """动态调整进给率"""
    feeds = []
    for i in range(1, len(points)-1):
        angle = calculate_angle(points[i-1], points[i], points[i+1])
        # 角度越小（拐弯越急），进给越低
        ratio = angle / math.pi  # 归一化[0,1]
        feed = base_feed * max(ratio, 0.4)  # 最低保留40%
        feed = max(feed, min_feed)
        feeds.append(feed)
    # 首尾补全
    feeds.insert(0, base_feed)
    feeds.append(base_feed)
    return feeds

    """生成加速段虚拟点"""
    dx = (end_point[0] - start_point[0]) / steps
    dy = (end_point[1] - start_point[1]) / steps

    for i in range(1, steps+1):
        x = start_point[0] + dx * i
        y = start_point[1] + dy * i
        f = feed_rate * (i / steps)  # 线性增速
        ramp.append((x, y, f))
    return ramp

    if not zlim[0] <= z <= zlim[1]:
        errors.append(f"Z={z} out of range {zlim}")
    return len(errors) == 0, errors

import pytesseract
from PIL import Image
 
def detect_numbers_in_image(image_path: str):
    """
    检测图像中所有数字及其边界框
    """
    pil_img = Image.open(image_path)
    data = pytesseract.image_to_data(pil_img, output_type=pytesseract.Output.DICT)
    numbers = []
    for i in range(len(data['text'])):
        word = data['text'][i].strip()
        if word.isdigit():
            x, y, w, h = data['left'][i], data['top'][i], data['width'][i], data['height'][i]
            numbers.append({
                'value': int(word),
                'bbox': (x, y, x+w, y+h)
            })
    return numbers

6.3.2 笔画顺序优化减少空走路径
针对多字符场景，采用最近邻启发式算法重新排序雕刻顺序：

def sort_contours_by_proximity(contours):
    if len(contours) <= 1:
        return contours
    ordered = [contours.pop(0)]
    while contours:
        last_centroid = np.mean(ordered[-1], axis=0)
        dists = [np.linalg.norm(last_centroid - np.mean(c, axis=0)) for c in contours]
        nearest_idx = np.argmin(dists)
        ordered.append(contours.pop(nearest_idx))
    return ordered
